# Support

- For installation and usage instructions, start with the [README](./README.md).
- Search [existing issues](https://github.com/M003aad/PicShot/issues) before opening a new one.
- For a reproducible bug, submit a [bug report](https://github.com/M003aad/PicShot/issues/new?template=bug_report.md).
- For a feature proposal, use the [feature request template](https://github.com/M003aad/PicShot/issues/new?template=feature_request.md).
- For a suspected security vulnerability, follow [SECURITY.md](./SECURITY.md) and do not use a public issue.

PicShot currently provides support through its documentation, GitHub issues, and the private security contact listed in the security policy.
