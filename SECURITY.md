# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 3.0 (manifest version) | Yes |

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use [GitHub Private Vulnerability Reporting](https://github.com/M003aad/PicShot/security/advisories/new) if it is enabled for this repository, or email [188705139+M003aad@users.noreply.github.com](mailto:188705139+M003aad@users.noreply.github.com).

Include the affected version, a clear description of the impact, and steps to reproduce the issue. Avoid including personal or sensitive data.

## Response and fixes

- Acknowledgement target: **24h**.
- Fixes will be prioritized according to severity and coordinated with the reporter where possible.

These response targets need to be set by the maintainer.
